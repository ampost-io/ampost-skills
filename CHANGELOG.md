# Changelog

## 0.1.0

First release.

- Claude Code plugin marketplace `ampost-skills` with the plugin `ampost`: the hosted Ampost MCP
  server (`https://api.ampost.io/mcp`, OAuth sign-in) and seven skills: `post-everywhere`,
  `blog-to-posts`, `schedule-week`, `repurpose-video`, `weekly-analytics-report`,
  `reconnect-accounts` and `csv-bulk-import`.
- The skills follow the Agent Skills spec, so they also load in Codex, Cursor, VS Code (GitHub
  Copilot), Gemini CLI, OpenCode and other agents that read `SKILL.md`.
